# AI Usage Info

## Sinn der Library
`lack/citymap` ist eine kleine PHP-Library für Postleitzahl-, Orts- und Umkreissuchen auf Basis einer SQLite-Datenbank.

Praktisch ist sie vor allem für:
- Lookup von `PLZ -> Ort`
- Suche von `Ort -> PLZ`
- freie Suche über Ort, Bundesland oder PLZ
- Umkreissuche über Koordinaten der PLZ-Datensätze

## Standarddaten im Repository
Standardmäßig liegen die generierten Daten hier:
- `resources/data.de.csv`
- `resources/data.de.sqlite`

Für normale Nutzung der Library reicht standardmäßig `new PostalMap()`, dabei wird automatisch `resources/data.de.sqlite` verwendet.

## Beispiele
- `examples/basic-usage.php`

## Zentrale Klassen

### PostalMap
Haupteinstieg für Abfragen gegen die SQLite-Datenbank.
- `PostalMap::open(?string $databasePath = null)` → `examples/basic-usage.php`
- `__construct(PDO|string|null $database = null)` → `examples/basic-usage.php`
- `getLocationByPostalCode(string $postalCode, string $countryCode = 'DE')` → `examples/basic-usage.php`
- `getLocationsByPostalCode(string $postalCode, string $countryCode = 'DE')` → kein eigenes Beispiel
- `getPostalCodesByLocation(string $query, string $countryCode = 'DE', int $limit = 20)` → indirekt wie `searchLocations()` nutzbar
- `searchLocations(string $query, string $countryCode = 'DE', int $limit = 20)` → `examples/basic-usage.php`
- `findWithinRadius(string $postalCode, float $radiusKm, string $countryCode = 'DE', int $limit = 100)` → `examples/basic-usage.php`
- `searchNearbyLocations(string $query, float $radiusKm, string $countryCode = 'DE', int $limit = 100)` → kein eigenes Beispiel

### PostalLocation
Wertobjekt für einen Treffer.
- Properties: `countryCode`, `postalCode`, `placeName`, `stateName`, `latitude`, `longitude`, `population`, `areaKm2`, `distanceKm`
- `PostalLocation::fromRow(array $row, ?float $distanceKm = null)` → interne Nutzung
- `toArray()` → `examples/basic-usage.php`

### Geo
Hilfsfunktionen für Geometrie.
- `Geo::distanceKm(...)` → indirekt über Umkreissuche
- `Geo::boundingBox(...)` → indirekt über Umkreissuche

## Empfehlung
Für neue Nutzung in diesem Paket normalerweise so vorgehen:
1. `new PostalMap()` aufrufen
2. optional bei Bedarf einen eigenen DB-Pfad oder ein `PDO` übergeben
3. mit `getLocationByPostalCode()`, `searchLocations()` oder `findWithinRadius()` arbeiten
